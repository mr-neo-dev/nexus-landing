# NEXUS — Cyborg Landing Page

A responsive, futuristic cyborg-themed landing page concept built with vanilla HTML, CSS and JavaScript. No 3D assets or frameworks required.

## Features
- Dark sci-fi visual system with acid-lime and cyan accents
- CSS-built cybernetic portrait, orbital diagrams and module illustrations
- Responsive mobile navigation
- Animated ticker, count-up stats, waveform and subtle pointer parallax
- Reduced-motion accessibility support
- Semantic sections and responsive layouts

## Run locally
Open `index.html` in a browser. For a local server, run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy
### Netlify
Drag the project folder (the folder containing `index.html`) into [Netlify Drop](https://app.netlify.com/drop).

### GitHub Pages
Push the contents of this folder to a GitHub repository, then enable Pages from **Settings → Pages**, selecting the main branch and root folder.

## Customize
- Edit copy and section content in `index.html`.
- Adjust colors and responsive styles in `styles.css` (`:root` variables).
- Interaction logic lives in `script.js`.
